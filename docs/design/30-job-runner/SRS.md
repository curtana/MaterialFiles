## 1. 목적과 범위

### 1.1 목적
파일 작업(복사·이동·삭제·압축 등)의 진행은 지금 알림으로만 보인다. 알림 채널 중요도가 낮고(`filejob/FileJobNotificationTemplate.kt:19` `IMPORTANCE_LOW`) 알림을 꺼 둔 기기에서는 작업이 도는지, 끝났는지 앱 화면에서 알 수 없다. 앱 화면에도 진행 상태(`FileJobService`의 진행 중 작업 목록 `runningJobs`, `FileJobService.kt:33`)를 관찰할 수 있는 통로가 없다 — 바깥에 드러난 것은 메인 스레드에서 한 번 읽는 개수 `runningJobCount`(`:100-102`)뿐이고 바뀔 때 알려 주지 않는다. 파일 목록 화면 툴바 끝 쪽에 작은 선 사람을 두어 작업이 도는 동안 달리고, 끝나면 결과(성공·실패/취소)를 자세로 보여 준 뒤 사라지게 한다.

### 1.2 범위
- 파일 작업의 진행·끝·결과를 화면에 알려 주는 **최소한의 상태 통로**(작업이 시작·끝날 때 알리는 것, 작업별 성공/실패·취소 구분). 작업 실행 로직은 바꾸지 않는다(4.2 C-1).
- 파일 목록 화면(`FileListActivity`) 툴바의 표시(달리기·만세·넘어짐 그림과 그 시간 규칙), 모션 줄이기 대응, 화면 낭독, 밝은·어두운 테마 대비, RTL.
- 표시를 켜고 끄는 설정 하나(기본 켜짐).

### 1.3 범위 밖 (요구사항 정리 v2 "범위 밖")
- 기존 알림(진행률·취소 버튼)의 변경.
- 파일 작업 엔진(`FileJob` 실행 로직) 자체의 변경 — 상태를 알리는 통로만 추가한다.
- 파일 목록 외 화면(설정·뷰어·속성 등)의 표시.
- #29 목록 갱신·로딩 표시 변경(같은 툴바·같은 파일을 건드리는 곳은 HLD에서 조율점으로 적는다).

## 3. 비기능 요구사항

### 3.1 환경
- 지원 API: minSdk 23 ~ targetSdk 36(`app/build.gradle:34,37`). API 26 미만에서도 모션 줄이기를 판정한다(시스템 설정의 Animator 길이 배율을 읽는다).
- 권한: 새 권한을 추가하지 않는다. 알림 권한 유무와 무관하게 동작한다.
- 루트/비루트, 로컬/원격(SMB·SFTP 등)/압축 파일 경로 모두 같은 방식(작업 종류·경로 종류에 따른 차이 없음).
- 새 런타임 의존성을 추가하지 않는다(4.2 C-3).

### 3.2 성능·자원
- 상태 통로는 작업 스레드의 처리 시간을 눈에 띄게 늘리지 않는다: 시작·끝에 각각 한 번 메인 스레드로 넘기는 일 외에 작업 중 반복 보고를 하지 않는다(진행률은 다루지 않는다).
- 애니메이션은 선 사람이 실제로 보일 때(화면이 시작됨 상태, 뷰가 붙어 있고 보임)만 돈다. 화면이 멈추거나 선 사람이 숨으면 그리기 갱신을 멈춘다.
- 메인 스레드에서 입출력을 하지 않는다(`Stability_ANR`).

### 3.3 접근성
- 설명(`Content_Description` 필수, `A11Y-2` 권장): REQ-30-12. 선 사람은 장식이 아니라 상태를 전하는 요소라 접근성 서비스에 노출하고, 목적(작업 상태)을 말한다.
- 상태 변화 알림: REQ-30-12(초점 이동 없는 알림, 반복 없음).
- 색 외 구분(`A11P-2` 권장): 결과(성공·실패/취소)는 색이 아니라 자세(만세·넘어짐)와 낭독 문구로 구분한다. 선 색은 상태와 무관하게 하나다.
- 대비(`Visual_Contrast` 필수, `A11Y-3` 권장): REQ-30-13 — 그래픽 요소라 3:1 기준.
- 터치 대상: 선 사람은 조작 요소가 아니다(REQ-30-09). `Touch_Target_Size`의 대상이 아니며, 주변 메뉴 항목의 터치 대상을 줄이지 않는다(REQ-30-02·14).
- 모션 줄이기: REQ-30-10. 규격 근거는 5장(원문 판독 필요)이고 요구사항 v2 7(오너 결정)로 정한다.

### 3.4 테마
- 밝은·어두운 테마, Material 3 켬·끔, 검은 어두운 테마(`BLACK_NIGHT_MODE`) 모두에서 REQ-30-13을 만족한다(`Theme_Support` 필수). 툴바와 같은 테마 속성을 쓰므로 테마 색(`THEME_COLOR`)을 바꿔도 따라간다.

### 3.5 RTL
- 선 사람은 툴바의 끝(end) 쪽에 놓인다(`RTL-1`). RTL에서는 툴바 메뉴가 왼쪽에 있으므로 선 사람도 왼쪽(메뉴 바로 오른쪽)에 놓인다.
- 달리기 그림은 방향이 있는 그림이다. RTL에서는 좌우를 반전해 끝 쪽을 향해 달리게 한다(`RTL-2`). 만세·넘어짐도 같은 방향 기준으로 반전한다.
- 확인: 개발자 옵션 "RTL 레이아웃 방향 강제"(`RTL-4`).
